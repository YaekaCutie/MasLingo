# MasLingo v1.1.8

日漫全平台 OCR 翻译器浏览器插件。根据 OCR 原理，可以自动检测当前可见页面中的文字区域翻译当前页面，或者框选翻译；翻译开启后，扩展在原图文字范围内修复背景并绘制中文。

由于原理决定，插件并不会像其它插件一样需要平台支持。

**⚠️服务器未上线**：识别由官方托管的 MangaOCR 后端完成，原则上普通用户不需要安装 Python、不需要下载模型，装完扩展就能用。但是由于服务器未上线，只能自行部署于本地。

## 安装与运行

### Windows 源码版快速启动（使用仓库最新功能）

先安装 Python 3.12，然后在下载或克隆的项目目录打开 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-local.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-backend.ps1
```

第一条命令创建 `.venv`、安装 CPU 依赖并下载和加载真实 OCR 模型；只需首次安装或更新依赖时运行。第二条命令启动后端，窗口需要保持打开。运行 `setup-local.ps1` 不需要激活虚拟环境。

打开 <http://127.0.0.1:8001/health> 确认后端已启动，再到 `chrome://extensions` 或 `edge://extensions` 打开开发人员模式，选择「加载解压缩的扩展」，加载本仓库的 `extension` 文件夹。已有发行版扩展时，先停用它，避免重复处理。

在扩展设置里将 OCR 后端地址设为 `http://127.0.0.1:8001`，配置翻译来源并保存，测试翻译成功后打开「自动识别全图」。这是持续自动翻译开关；弹窗诊断信息里的「识别整页气泡」只处理一次当前可见区域。新安装默认选择 DeepSeek，需填写自己的 API Key；已有的来源选择（包括关闭翻译）保持不变。Google 免费翻译需要网络可访问 Google，国内可尝试必应或配置 AI 接口。

使用 DeepSeek 时，选择「DeepSeek」，模型填写或采用默认值 `deepseek-flash`，在扩展设置中填写自己的 API Key 并保存。接口地址应为 `https://api.deepseek.com/v1/chat/completions`；无需把 Key 写进仓库或 OCR 后端配置。

更新源码后重启后端，在扩展管理页点「重新加载」，再刷新漫画页面。换端口可运行 `.\start-backend.ps1 -Port 8002` 并同步修改扩展的 OCR 后端地址。

### 自动日漫识别与擦字

自动模式现在使用本机 ONNX 漫画文字检测模型，输出文字块和笔画掩膜，再由 MangaOCR 读取日文。长条漫画按宽度保留分辨率、用有重叠的分段识别，避免整条缩小后漏掉小字。对白检测不依赖白色气泡，也保留 RGB 颜色信息。

检测器会按文字列间距拆分粗框，再依据笔画证据收紧边距，避免把相邻气泡串成一段或把边线带进小字识别。未通过置信度检查的日文小框会额外保留 2 像素上下文重读一次，擦字范围不会随之扩大。

自动模式检查文字附近纹理和掩膜覆盖率：纯色区域使用局部底色，平滑渐变在笔画掩膜内修补；掩膜外保留原画。背景复杂或掩膜不可信时保留原文，在阅读侧栏显示旁注；点击「定位原文」会短暂标出对应区域。风险判断是保守的启发式方法，仍可能误判。目标为普通对白与旁白，不以拟声词和艺术字作为验收目标。

封闭、平滑的气泡内部会单独确认，减少普通气泡误用旁注。多行译文优先竖排；竖排破折号沿竖向显示，汉字「一」保持原字形。侧栏旁注替代了旧版可拖动的页面卡片。网页文字另有原文旁的快捷操作条，可直接调整语言、来源和覆盖方式。

首次安装会额外下载约 95 MB 检测模型，后续识别和擦字均在本机完成。模型来源与校验值见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。离线环境需预先完成 `setup-local.ps1`；也可通过 `MAS_TEXT_DETECTOR_MODEL` 指向已下载且校验一致的 ONNX 文件。`MAS_TEXT_DETECTOR=heuristic` 可切回旧检测器进行对照，但没有新模型的笔画修复层。

### 本机部署

```
Edge / Chrome 扩展（加载 extension 文件夹）
        │  http://127.0.0.1:8001
        ▼
你电脑上的 FastAPI + MangaOCR（start-backend.ps1）
```


### 1. 安装 Python 3.11.x / 3.12.x

访问 <https://www.python.org/downloads/> 下载安装，**安装时勾选 “Add python.exe to PATH”**。装完打开 PowerShell 确认：

```powershell
python --version
```

显示 3.11.x 或 3.12.x 即可。

### 2. 下载本项目

```powershell
git clone https://github.com/YaekaCutie/MasLingo.git
```

若未安装 Git，在 GitHub 页面点 **Code → Download ZIP**，解压到本地目录。

### 3. 创建环境并安装依赖

在项目目录里执行：

```powershell
cd MasLingo
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
```

- 如果提示“禁止运行脚本”：先执行 `Set-ExecutionPolicy -Scope Process Bypass`，再运行激活命令。
- 国内网络下载慢，可以在 pip 命令末尾加 `-i https://pypi.tuna.tsinghua.edu.cn/simple`。

### 4. 启动后端

```powershell
.\start-backend.ps1
```

- **首次启动会联网下载 OCR 模型**（数百 MB，缓存在 `C:\Users\<你>\.cache\huggingface`），需要一两分钟；日志出现 `OCR ready` 就是就绪。
- **这个窗口保持开着**，关掉窗口就等于后端停止；`Ctrl-C` 可以停止。

### 5. 验证后端

浏览器打开 <http://127.0.0.1:8001/health>，看到

```json
{"ok":true,"backend":"ready","ocr":"mangaocr","busy":0,"concurrency":2,"free_translate":true}
```

属于成功响应示例；并发数等字段以实际配置为准。

### 6. 加载扩展

Edge 地址栏输入 `edge://extensions`（Chrome 为 `chrome://extensions`）→ 打开「开发人员模式」→「加载解压缩的扩展」→ 选择项目里的 `extension` 文件夹。装好后工具栏出现 MasLingo 图标。

### 7. 指向本机后端

`http://127.0.0.1:8001` 与 `http://localhost:8001` 是扩展内置的默认回退地址，**通常什么都不用设置**。只有换过后端端口（见常见问题）时，才需要到扩展「识别设置」里手动填写后端地址。

### 8. 使用

打开任意漫画页 → 点 MasLingo 图标 → 框选翻译某个区域，或开启「漫画自动翻译」。新安装默认使用 DeepSeek，请先在设置中填写 API Key 并保存；也可选择其他来源或「关闭翻译」仅识别原文。

### 9. 更新方式

- **后端**：`git pull` 后重启——`Ctrl-C` 停掉，再运行 `.\start-backend.ps1`。
- **扩展**：到 `edge://extensions` 点 MasLingo 下的「重新加载」，然后刷新漫画页。

### 10. 可选：开机自启

按 `Win+R` 输入 `shell:startup` 回车，把 `start-backend.ps1` 的**快捷方式**放进打开的文件夹。以后登录 Windows 会自动启动后端（会弹出一个 PowerShell 窗口，属正常）。

### 本机部署常见问题

- **端口 8001 被占用**：多半是已经有一个后端在跑（任务管理器里找 `python` 进程）。换端口启动：`python -m uvicorn backend.app:app --host 127.0.0.1 --port 8002`，然后到扩展「识别设置」把后端地址填成 `http://127.0.0.1:8002`。
- **识别一直失败**：先确认第 5 步的 `/health` 能打开；再确认扩展设置里的后端地址为空或者与本机地址一致。
- **首次识别很慢**：模型还在加载或下载，属正常；之后会快很多。
- **模型下载中断**：重新运行 `.\start-backend.ps1` 会续传，已下载的部分保留在 `~/.cache/huggingface`。
- **数据去哪了**：使用本机 OCR 地址时，发送给 OCR 的画面经本机回环地址传输；翻译开启后，文字会发给所选翻译服务。

## 数据流与限制

`图片/长图分段 → 配置的本地 OCR 后端 → ONNX 文字块与笔画检测 → MangaOCR → 所选翻译服务 → 透明修复层和译文`

「自动识别全图」持续发现视口附近的大图或画布，优先读取原始图片字节；长图按宽度保留分辨率，分段之间保留重叠并对识别结果去重。读取失败时，只有最外层且处于活动状态的标签页可以回退截图。一次性的整页识别使用当前视口截图，手动框选则只读取所选区域。

自动检测使用 RGB 文字检测模型，不要求白色气泡；横竖排由识别器判断，竖排列按从右至左读取。识别结果仍经过置信度过滤。检测和识别不是无误的：小字、严重压缩、纹理、相邻对白以及非日文水印都可能漏检或误读。

自动模式在后端生成透明笔画修复层。纯色背景填补局部底色，平滑渐变背景只在掩膜内修补；前端将修复层与译文对齐到原图，保留小数坐标以适配页面缩放。复杂纹理或掩膜不可信时，保留原图，在独立阅读侧栏显示译文，并提供「定位原文」按钮；关闭翻译时不添加这类卡片。手动单区域识别仍使用浏览器中的像素掩膜路径。修复不是原画还原，安全检查通过也不能保证完全没有痕迹。

新安装默认选择 DeepSeek，配置 API Key 后可进行翻译；已有的来源设置保持不变，也可选择「关闭翻译」仅做 OCR。漫画的默认翻译方向为日文到简体中文：Google 翻译请求固定使用 `ja → zh-CN` 并整条提交 OCR 文本；OpenAI-compatible Chat Completions API 结合当批条目的上下文翻译，并要求保留原意、编号及条目数量。可在扩展设置选择兼容接口并填写 endpoint、模型以及可选 API Key，也可选择其他翻译 API。设置（包括 Key）仅存于 Chrome `storage.local`；当前翻译来源通常由扩展直接请求；自建后端来源才调用后端。Key 不写入后端配置或日志。选择在线服务会将识别文本发送给该服务。也可配置本地运行的兼容服务。

网页自动翻译：在阅读侧栏、扩展弹窗或设置中打开「网页自动翻译」，按阅读位置分批显示双语正文，支持标题、图注、列表、表格单元格、动态内容和开放的 Shadow DOM。有论文正文时优先翻译文章区域；菜单和按钮可通过悬停翻译。原文的引用链接、公式和行内格式保留，上标文献编号在发送时使用 `[1]` 形式，避免把模型名称或数值与引用编号混在一起。关闭后移除译文。此开关与漫画自动翻译独立，网页文字翻译不依赖 OCR 后端。

网页显示模式：在阅读侧栏或设置中选择「双语对照 / 纯译文 / 纯原文」，默认双语对照。纯译文直接覆盖适合替换的段落；切回双语或原文时恢复原节点、链接和事件。公式、控件、表格等复杂结构保留原文，并在译文卡中提示。纯原文隐藏自动译文并暂停新的自动翻译请求，已经发出的请求仍可能完成；悬停和划词开关独立生效。显示切换复用已完成的译文，翻译配置或正文变化时才重新翻译。此模式目前用于网页自动翻译，不控制图片、视频或文档输出。

视频字幕：视频下方的控制条（不覆盖画面）提供「翻译字幕」「无字幕识别」、字幕轨选择以及双语／纯译文／纯原文模式；阅读侧栏的「定位视频与字幕控制」可定位视频。点击「翻译字幕」后读取 HTML5 字幕轨，并预翻译接下来约 25 秒的字幕；也能读取 YouTube、Bilibili 播放器已显示的网页字幕。需先在播放器开启相应字幕；网站自定义、封闭播放器或跨域字幕轨不保证可读。翻译复用当前来源、目标语言和专业术语库，原文模式不发起新的翻译请求。停止时恢复原生字幕显示；拖动进度、换视频或改翻译设置会丢弃过期结果。全屏时隐藏控制条，退出全屏后可调节设置；视频元素自身全屏使用原生字幕轨，画中画是否显示字幕由浏览器决定。

无字幕视频使用本地 Faster Whisper 语音识别。安装 `.venv\Scripts\python.exe -m pip install -r backend/requirements-speech.txt`，然后运行 `./start-backend.ps1 -Speech`。默认 CPU/int8 的多语言 `base` 模型，首次识别下载到 `.hf/speech`；可用 `MAS_SPEECH_MODEL` 指定模型名或本地目录，`MAS_SPEECH_THREADS` 调整线程数。其他启动方式需设置 `MAS_ENABLE_SPEECH=1`；默认未开启此接口。点击「无字幕识别」后，在浏览器选择**当前标签页**并勾选共享音频，再播放视频；无需麦克风。每约 5 秒识别一段，字幕存在采集、推理和翻译延迟，不是零延迟同传；低配机器来不及处理时会跳过片段，连续词句跨片段、音乐和嘈杂语音可能误识别。音频仅发给配置的后端（未配置则使用本机），文字发给所选翻译来源；共享画面不上传。支持桌面 Chrome/Edge 的 HTTPS 页面或 localhost；不支持共享音频、受保护媒体或禁止共享的 iframe 会提示失败。停止、视频结束、页面离开或浏览器停止共享都会释放采集。

视频回归：`node deploy/check-video-translate.mjs` 验证字幕轨、播放器网页字幕、模式缓存、跳转恢复和窄屏布局；`python -m unittest backend.tests.test_speech -v` 验证音频接口及大小／时长限制。实际语音链路需启动语音后端，设置 `MAS_VIDEO_WAV` 为合成语音 WAV 路径，运行 `node deploy/check-video-translate.mjs --speech --live`，按隐藏提示输入测试 Key；测试自动选择其合成视频标签页进行声音采集，截图由 `MAS_SCREENSHOT_DIR` 指定。

右键图片翻译：在网页图片上右键，选择「MasLingo：翻译这张图片」，会使用当前翻译来源识别并翻译这一张图，不开启漫画自动翻译，也不扫描其他图片。支持 iframe 中的图片、页面上重复出现的同地址图片，以及小于自动扫描尺寸的图片。正在处理时重复点击不会重复提交，完成后再次点击可重新识别；图片变更或消失时丢弃旧结果。仍需可用的 OCR 后端和已配置的翻译来源，失败原因会显示在阅读侧栏。更新扩展后请重新加载扩展并刷新已打开的网页。

悬停翻译：打开「悬停翻译」后，把鼠标停留在文字上，可在原文旁的圆角横向操作条切换源语言、目标语言、翻译来源、双语／覆盖／原文模式，并直接覆盖或还原；详细结果同时显示在阅读侧栏。移开鼠标后仍可阅读，可定位原文、关闭或重试，也可更改该段落的源语言和目标语言。网页自动翻译仍在原文下方排版。设置或正文变化后刷新缓存，关闭后丢弃晚到的结果。阅读论文可选择「学术」术语库。

划词词典：阅读侧栏和设置页的「划词词典」开关默认开启，仅支持 AI 翻译来源。选择非 AI 来源或关闭翻译后，开关变灰、无法点击，也不会弹卡或发送划词请求；切回 AI 后恢复原来的开关偏好。选中一段文字后，阅读侧栏会显示翻译结果；选中单词（中日文单字/词、英文单词等不含空格的短词）时，卡片会按权威辞典的编排方式列出全部常见义项、每个义项的词性、原文例句与例句译文，并根据上下文标出和加深高亮「本文义项」及其词性。释义由 AI 参照《広辞苑》《新明解国語辞典》《现代汉语词典》《牛津》《朗文》等辞典整理，不是在线辞典的逐字原文，仅供参考。选中短语则直接显示普通翻译；输入框和文本域里选中的文字同样可以翻译。选中普通文字后，原文附近的操作条也可直接切换语言与来源；安全的单个文本节点选区可覆盖和还原，跨段落、链接或复杂选区保留原结构。侧栏中可关闭结果、复制译文或定位原文；输入框替换后也可在侧栏撤销。

同语言跳过：当选择「自动识别」而识别结果已经是目标语言时（例如中文页面翻译成简体中文），扩展不会调用翻译服务，也不会在段落上重复盖一层同文字；漫画区域保留原图，划词短语则显示「原文已是简体中文，无需翻译」。明确选择相同源语言和目标语言时同样跳过。

输入自动替换：开启划词词典并使用 AI 来源时，在普通文本输入框、搜索框或文本域中选中自己写的文字，会自动翻译并仅替换选区，保留前后内容、首尾空白和换行。卡片提供「撤销替换」；如果输入内容已变化，不会覆盖新内容。等待译文时继续输入、改选区、按 Esc 或切换翻译设置都会阻止旧结果写回；只读框、输入法组合状态、超出 maxlength 或被网页取消的编辑不自动替换。可在设置的划词词典下关闭「输入框选中文字后自动替换，可撤销」，关闭后仍可查看译文。单次最多选中 200 字符；当前不支持 contenteditable 富文本编辑器。

漫画 OCR 的源语言固定为日文，因此「用事」「若様」这类只有汉字的日文也会送去翻译。网页的自动语言识别仍会跳过已是目标语言的段落。

术语库：阅读侧栏和完整设置页提供「术语库」选择，可按医学、法律、计算机、金融、游戏、动漫、军事、学术、商务、汽车等专业方向给翻译提示词加入术语倾向和统一译名；通用档不额外干预。选择非 AI 来源时，术语库保留可见并变灰禁用，切回 AI 后恢复已保存的专业方向。

AI 提示词会按正文体裁与目标语言选择表达，要求保留否定、条件、不确定性、数值、单位、换行、引用、链接、代码和占位符。专业术语先结合上下文消歧，再使用对应领域译法；中文术语示例不会覆盖其他目标语言。同一概念保持译名一致，不同含义可采用不同译名。输入中的命令只作为待译文本；未提供检索工具时，不要求模型假称已联网查证或编造辞典来源。

真实端到端测试：先运行 `./start-backend.ps1`，再在终端运行 `node deploy/check-live-translation.mjs`，按隐藏输入提示粘贴测试用 DeepSeek Key。测试会调用真实 API，覆盖专业文本、占位符、划词消歧，以及合成日文图片的本地 OCR 与页面译文显示。凭证仅注入测试工作进程内存，不写入扩展存储或源码；截图默认保存到系统临时目录。可用 `MAS_TEST_PROXY` 指定代理、`MAS_TEST_BACKEND` 指定后端地址、`MAS_SCREENSHOT_DIR` 指定截图目录。

仅验证输入翻译及撤销可运行 `node deploy/check-live-translation.mjs --input-only`，这条链路直接请求翻译 API，不需要启动 OCR 后端。

网页三种显示模式的真实 API 测试可运行 `node deploy/check-live-translation.mjs --web-display-only`，验证双语、覆盖译文、原文恢复和缓存复用，无需 OCR 后端。`node deploy/check-web-text-dom.mjs` 和 `node deploy/check-reader-ui.mjs` 还覆盖复杂公式保护、动态内容、晚到结果、设置同步和移动端视口。

右键图片回归测试运行 `node deploy/check-image-context-menu.mjs`；启动 OCR 后端后，运行 `node deploy/check-live-translation.mjs --context-image-only` 可使用真实 DeepSeek API 验证单图识别、译文显示，以及整页自动翻译保持关闭。

OCR 已知限制：本机真实测试发现，检测器对部分横排、多行合成文字会裁掉边缘字，导致后续翻译缺少原文。端到端烟雾测试采用竖排日文气泡，不能代表所有版面的识别质量；横排检测范围仍需单独修复。可用 `node deploy/check-live-translation.mjs --image-only` 仅复核图片链路。

选择 AI 翻译来源后，可在完整设置中选择 Low、High、Max 三档润色强度。较高档位更强调上下文和逐条复核；只有接口实际提供检索工具时才能联网核对。

## 隐私与数据

这是使用前必须知道的部分：

- **仓库源码默认使用本机 OCR 后端**，图片通过 `127.0.0.1` 传输；配置远程后端或使用内置托管地址的发布包时，画面才会发送到那台远程服务器。
- 托管后端**只做 OCR**：不写入请求体日志、不做训练、不做广告用途、不长期保存截图。进程只保存模型，不保存用户图像。
- 想让数据完全不出本机：按上面「本机部署」把后端跑在自己电脑上；截图只经 `127.0.0.1`，不离开这台电脑。
- **翻译来源可独立选择**，新安装默认为 DeepSeek，需要自行配置 API Key。翻译时会把识别文本发给所选服务；选择「关闭翻译」就只做 OCR。已有用户的来源选择不会自动覆盖。
- 划词词典会把选中的文字和附近的一小段上下文发给当前 AI 来源；关闭「划词词典」或切换到非 AI 来源后不会再发送划词请求。
- 悬停翻译会把鼠标停留或键盘聚焦的文字块发给翻译来源；网页自动翻译会在阅读区域及附近分批发送文字。关闭对应模式后不再启动其新请求；已经发出的请求可能继续完成，但关闭后不会恢复译文卡片。
- 视频字幕只在主动开启后送译；无字幕识别另需浏览器授权共享标签页声音。整个所选标签页的声音都会进入识别，请选择当前视频标签页并关闭其他同时发声的内容。音频片段不写入应用日志或持久文件；语音模型驻留内存，关闭后已发出的请求可能完成，但不会重新显示字幕。
- 相关信息：自动漫画翻译开启后会处理页面附近符合条件的图片；需要截图回退时仅允许活动标签页。手动框选和整页识别也会读取所选画面。

## 常见问题

- **识别很慢或失败**：使用托管后端时，第一次请求要等模型加载（托管实例已开启预加载，通常不会遇到）。本机部署时首次运行需初始化 MangaOCR 模型，确认安装依赖时网络可用，并为模型文件和运行时预留足够磁盘及内存。
- **自动识别要等几十秒**：整页模式要检测并逐个识别最多 80 个区域（普通单页几秒到十几秒，密集双页可能二十多秒到一分钟），在低配服务器上是正常耗时；手动框选单个区域通常 1–3 秒。嫌慢就用框选。
- **自动识别结果为空或区域不准**：默认使用漫画文字检测模型，但小字、压缩和复杂画面仍可能漏检或误读；确认未启用旧的 `MAS_TEXT_DETECTOR=heuristic`，也可手动框选单个文字区域。
- **从源码加载的扩展识别一直失败**：仓库里的 `extension/` 没有内置托管后端地址，会回退到本机 `127.0.0.1:8001`——按「本机部署」先把后端跑起来即可；发布用的 `.crx` 不受影响。
- **结果只有日文、没有中文**：打开扩展设置，检查翻译来源是否为「关闭翻译」；默认的 DeepSeek 需要填写有效 API Key 并保存。也可选择其他已配置的来源。翻译未启用或服务报错时，页面会提示原因并保留日文原文。
- **翻译报“无法连接「XX」（域名）：Failed to fetch”**：说明这个翻译服务从你的网络**无法直连**，也可能与代理、浏览器权限或接口配置有关。国内网络访问 Google 翻译、OpenAI、Anthropic 等通常需要代理；Google 翻译是最顺手的免密钥来源，也最容易连不上。到“识别设置”里把翻译来源换成「必应翻译」或「MyMemory」（免密钥；是否可用取决于网络和服务状态），或 DeepSeek、通义千问、智谱等（需要各自的 API Key），或本机运行 Ollama。
- **提示“请求过于频繁”**：托管后端对每个 IP 做了限流，稍等几十秒再试即可。

### 阅读侧栏与新版界面

需要 Chrome / Edge 116 或更新版本。更新后重新加载扩展并刷新网页，点击工具栏 MasLingo →「打开阅读侧栏」。侧栏占用浏览器独立空间，悬停、划词和漫画旁注集中显示；关闭侧栏后，工具栏角标提示当前页已有结果。

设置按「阅读方式 / 翻译来源 / 识别与显示」分组，切换分组保留未保存的输入，点击「保存设置」统一保存。页面反馈使用平面化样式和轻量动画，遵循系统的减少动态效果偏好。视频控制和常规字幕位于视频下方；全屏与画中画使用原生字幕。

UI 回归入口为 `deploy/check-reader-ui.mjs`；旧浮窗的形变、跑马灯及拖拽测试已从 CI 换为侧栏交互测试。详细验证范围见 [UI 重构说明](docs/UI_REDESIGN.md)。

快捷操作条的语言与来源选择仅影响当前段落或选区，不改全局偏好；需要密钥的来源仍须事先配置。普通文字块优先嵌入操作条，其他位置在不覆盖选区时悬浮显示；窄屏可横向滚动控件。

快捷操作默认缩略为原文末尾附近的 24px「译」按钮，不占文档行高；点击展开，收起后恢复缩略。展开预览直接显示译文正文，不添加「译文：」标签。
