后端服务

识别时，页面截图会发送到上面这个后端；它只用于 OCR，不做其它用途。

翻译模式

启用翻译时，OCR 文本会按日文翻译为简体中文；默认关闭翻译。
OpenAI-compatible 可配置云端服务或本地兼容服务（如 Ollama）。只有选择相应模式后才会发起翻译请求。
API Key 仅保存在此浏览器的扩展本地存储中，随翻译请求发送到该接口。
