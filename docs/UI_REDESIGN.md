# 阅读侧栏 UI 重构

本文对应 `2e902ae` 的实现；工作背景、代码来源与验证结论见 [工作报告](IMPLEMENTATION_REPORT_2026-11-01.md)。

工具栏弹窗以「打开阅读侧栏」为主入口；网页、漫画、划词、视频使用统一的白底、蓝色强调、细分隔线和轻量状态动画。

## 行为变化

- 浏览器原生侧栏承载悬停译文、划词词典、输入框替换撤销和漫画旁注。页面不再出现常驻控制浮窗。
- 网页自动双语译文仍在正文流中；保留原文、纯译文和双语切换。
- 漫画不可靠的修补保留原图，旁注中的定位操作短暂勾出对应区域。
- 视频控制和普通字幕占据视频下方的页面空间；全屏和画中画尝试使用原生字幕轨；画中画显示取决于浏览器。
- 设置分为阅读方式、翻译来源、识别与显示。分组切换保留草稿，保存时保留未重新填写的密钥。
- 结果按标签页和文档区分；历史仅留在内存中，限制数量，并在文档切换时清理。后台休眠恢复后重新注册来源。
- 动画遵循系统「减少动态效果」；侧栏提供键盘焦点、状态播报、来源定位、复制和关闭操作。

## 验证

`check-reader-ui.mjs` 在 Chromium 中加载实际侧栏、设置页、弹窗和内容脚本，以模拟 Chrome 消息传输验证来源路由、划词词典、输入框撤销、失败重试、设置保存、窄屏布局、减少动态效果和视频布局。它不验证浏览器原生侧栏窗口本身。

`check-web-text-dom.mjs` 覆盖标题、链接、表格、引用、动态内容、开放 Shadow DOM、延迟响应和显示模式；`check-auto-lifecycle.mjs` 与 `check-inpaint.mjs` 覆盖漫画修补、图片替换和保留原画的旁注。CI 保留扩展加载与真实模拟服务往返检查。

视觉复核对照设计预览：侧栏与正文空间分离；统一白蓝配色；操作与结果层级明确；设置按组展开；280px 侧栏和 390px 设置页无横向溢出。

本地运行环境限制了未打包扩展加载，因此本次浏览器检查使用真实页面和脚本配合模拟扩展 API；Windows Chrome / Edge 原生安装体验仍需用户端确认。需要 Chrome / Edge 116 或更新版本。

## 原文旁快捷操作

后续修改补充了圆角横向操作条：悬停段落或划词后可直接切换源语言、目标语言、翻译来源、双语／覆盖／原文，以及覆盖／还原按钮。普通段落优先嵌入页面，其他位置在选区之外浮动；窄屏横向滚动，关闭按钮保持可见。来源和语言仅作用于当前结果，密钥仍在完整设置中管理。跨段、链接或复杂选区不执行覆盖；安全选区恢复时还原原节点，宿主页面更新优先于旧内容。

快捷操作默认缩略为原文末尾附近的 24px「译」按钮，不占文档行高；点击展开，收起后恢复缩略。展开预览直接显示译文正文，不添加「译文：」标签。
