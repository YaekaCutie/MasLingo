# MasLingo 工作报告

本文重新叙述从基线 `b66bb68` 到 UI 提交 `2e902ae` 的工作。用户最初希望审查仓库并让源码在 Windows 上运行，之后优先处理日漫识别与擦字、网页翻译交互和界面重构。审查集中在相关模块和运行链路，不表示已经逐文件完成人工审查。此报告区分本次工作和期间从远端拉取的其他更新。

## 主要改动和影响

| 阶段 | 发现的问题与原因 | 改动和结果 |
| --- | --- | --- |
| Windows 源码运行 | 现有发行版与仓库功能不同，模型、依赖和启动过程不够明确 | 完善 `setup-local.ps1`、`start-backend.ps1` 与本机说明。模型预加载失败时明确报错；首次运行需要下载模型和依赖。未按本次要求制作安装包。 |
| 漫画文字检测 | 灰度启发式检测难覆盖彩色、无气泡和相近亮度的文字；长图整体缩放损失小字 | 接入 RGB comic-text-detector ONNX 预训练模型，按重叠分段处理长图，依据文字列间距拆分粗框并收紧 OCR 边距。模型与分组仍可能漏检或误分。 |
| OCR 与翻译 | 小字裁切容易带入气泡边线，纯汉字日文可能被误判为中文而跳过 | 对部分未通过置信度检查的日文小框增加最多 2 像素上下文重读；漫画按已知日文源语言发送翻译。MangaOCR 权重未更换，低分辨率文字仍可能误读。 |
| 漫画擦字 | 矩形覆盖、白底回退及粗掩膜可能破坏画面或留下文字边缘 | 后端按笔画生成透明修复层，限制局部修复；结合气泡内部底色、纹理及掩膜可信度判断是否修补。复杂或不可靠区域按用户偏好保留原图与原文。该判断不是背景还原的保证。 |
| 竖排与旁注 | 普通气泡可能被误判为复杂背景；多行排版过小，破折号与「一」不易区分 | 改进平滑气泡判断，多行优先竖排，调整字号与分列；竖排破折号旋转而「一」保持字形。早期旁注使用可拖动页面卡片，后续 UI 重构将它迁入阅读侧栏，可定位并短暂标出对应原文区域。 |
| 图片生命周期 | 换图、关闭任务或重试时旧结果可能出现，失败图片可能反复处理 | 跟踪媒体变化和任务代次，清理旧图层，限制重试，丢弃过期结果并阻止关闭后继续启动后续流程。已经发出的推理请求不一定能立即中止。 |
| 网页翻译 | 论文标题、图注、列表、表格、动态文字和部分页面元素存在覆盖或交互问题 | 扩大可翻译文本单元并保留链接、公式和引用；改进悬停、自动翻译、设置变化及过期响应处理。自动双语译文位于正文流，复杂结构保留原文。 |
| 界面与交互 | 页面内控制窗和结果可能遮挡正文或漫画 | `2e902ae` 使用浏览器原生阅读侧栏承载悬停、划词、输入框撤销和漫画旁注；重做工具栏弹窗、设置页、平面样式和轻量动画。视频控制位于视频下方。设置分组切换保留未保存内容；保存时保留未重新填写的密钥。 |

## 测试证据与边界

早期三张 ZIP 漫画实图，在接入 ONNX 后的中间版本与分组修复后相比，接受的文字组分别从彩色六格 10 增至 14、黑白双页 18 增至 21、黑白校园 6 增至 9；旁注数分别从 3、2、0 变为 1、0、0。组数增加既包括找回漏读，也包括拆分粗框，**不是识别准确率**，且起点不是原始仓库的同图基线。彩漫紫底旁注区域在当次合成对照中保持原图 RGB 不变。早期六组合成样本的检测框覆盖率用于对照已知文字像素，不能代表真实漫画总体准确率；合成背景测试也不能证明被文字遮挡的真实画面已完全还原。

先前报告记录过 91 项后端单元测试通过，以及真实 DeepSeek 链路和漫画样本测试；这些是当时的结果，并非本文更新时重新运行的证明。UI 提交前，本地通过了扩展静态检查、网页 DOM 回归、漫画生命周期与修补检查、日文源语言检查，以及使用实际 UI 脚本和模拟扩展 API 的 Chromium 侧栏检查。侧栏检查包含词典、撤销、重试、设置保存、窄屏、减少动态效果和视频布局。当前环境限制了未打包扩展加载，**Windows Chrome / Edge 原生侧栏和完整安装流程仍需实机确认**；远端 CI 结论以 GitHub Actions 实际运行结果为准。

## 当前使用与限制

使用源码版时，在 Windows 运行 `setup-local.ps1` 和 `start-backend.ps1`，在 Chrome / Edge 116 或更新版本加载 `extension` 文件夹，更新后重新加载扩展并刷新网页。工具栏「打开阅读侧栏」提供阅读和设置入口；完整步骤见 [README](../README.md)。

普通日漫对白与旁白是当前重点，拟声词和艺术字不作为验收目标。小字、复杂纹理、相邻对白、压缩图和横排多行仍可能漏检、误读或误擦。复杂背景采用保守策略时，原文会保留并在侧栏显示译文。不同网站的视频字幕和画中画能力取决于播放器与浏览器；无字幕语音识别需用户主动共享标签页声音并配置可选后端依赖。

模型来源、校验与许可见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)，技术路径见 [ARCHITECTURE.md](../ARCHITECTURE.md)，界面细节和验证方法见 [UI_REDESIGN.md](UI_REDESIGN.md)。

## 后续原文操作条调整
